# Expense Tracker Web Application

A responsive Expense Tracker Web Application built using HTML, CSS, and JavaScript that helps users manage earnings and expenses with real-time balance calculation.

## Features

* Add income and expense transactions
* Edit existing transactions
* Delete transactions
* Real-time balance calculation
* Dynamic transaction rendering using JavaScript
* Responsive and mobile-friendly UI
* Interactive transaction action buttons

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* DOM Manipulation

## Project Structure

```bash
expense_tracker/
│
├── index.html
├── style.css
└── index.js
```

## How It Works

* Users can enter transaction details and amount.
* Income and expense values are updated dynamically.
* Transactions are displayed instantly on the screen.
* Users can edit or remove transactions easily.
